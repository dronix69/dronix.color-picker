# Color Picker (`dronix.color-picker`)

Omarchy shell plugin for inspecting, picking, and converting colors across multiple formats:

- **HEX** (`#3b82f6`)
- **RGB** (`rgb(59, 130, 246)`)
- **RGBA** (`rgba(59, 130, 246, 1)`)
- **HSL** (`hsl(217, 91%, 60%)`)
- **HSV** (`hsv(217, 76%, 96%)`)
- **OKLCH** (`oklch(0.623 0.188 259.8)`)

## Features

- **Interactive Color Wheel**: Full chromatic color wheel to visually pick Hue and Saturation in real time.
- **Value / Brightness Slider**: Horizontal gradient slider to adjust brightness from black to full saturation.
- **Screen Eyedropper**: Click "Pick Screen Color" (or right-click the bar icon) to pick any pixel from your screen using `hyprpicker`.
- **Live Conversion**: Converts any picked or entered color instantly into HEX, RGB, RGBA, HSL, HSV, and OKLCH.
- **One-Click Copy**: Click any format row or its copy button to copy that format directly to your clipboard.
- **Recent Swatches**: Quick access to recent colors for comparison and reuse.
- **Adaptive Bar Icon**: The bar icon dynamically tints to the currently selected color.
- **i18n Ready**: Full localization for English and Spanish.
